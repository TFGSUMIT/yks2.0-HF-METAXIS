# Contributing

METAXIS is currently in research and discovery. Changes should be small,
traceable, and explicit about what they prove.

1. Link work to the METAXIS root or a child issue.
2. Keep providers behind the brain adapter contract.
3. Add or update tests for contract behavior.
4. Record model, runtime, dataset, and service licenses exactly.
5. Include measured evidence before changing a research gate to green.
6. Do not commit credentials, endpoint tokens, private prompts, or user data.

Use concise commits and describe validation in pull requests.
