# METAXIS Ownership Boundary

## Own immediately

Threads, turns, plans, agent lifecycle, scheduling, workspaces, Git isolation,
tools, context assembly, governed memory, permissions, approvals,
interruption, retry, recovery, evaluation, replay, evidence, prompts, policies,
and operational history.

## Rent initially

High-quality inference, GPU capacity, large-context processing, reasoning
throughput, burst concurrency, and specialist model capability.

## Internalize progressively

Model weights, inference runtime, GPU placement, capacity, optimization,
fine-tuning, availability, and eventually physical hardware.

## Never delegate to the brain

Source truth, credentials, authorization, privilege elevation, durable-memory
authority, final action policy, evidence custody, workspace ownership, or
mission rules.

AXIS consumes a pinned METAXIS capability manifest and supplies mission-specific
authorization. It does not fork the reusable agentic core.
