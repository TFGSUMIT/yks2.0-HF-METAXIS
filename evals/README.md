# METAXIS Evaluation Lane

Phase 0 compares pinned model revisions through one brain contract.

## Required candidate record

- Hugging Face repository and immutable revision
- actual model, code, dataset, container, and service licenses
- gating and intended-use restrictions
- context, tool-call, precision, and hardware capabilities
- runtime and prompt-template versions
- data boundary, egress, retention, and training-use posture

## Common evaluation dimensions

1. reasoning and recovery
2. repository-scale coding
3. normalized tool-use behavior
4. latency, throughput, and concurrency
5. context-budget behavior
6. failure, retry, fallback, and degraded operation
7. cost and utilization
8. provider-neutral export and replay

No candidate is promoted without linked evidence and an operator decision.
